# Niubility Idle

一款使用 Godot 4.2 (C# / .NET) 开发的放置挂机游戏。

## 游戏特性

- **轮转产出**:彩色圆圈绕轴旋转自动产出,10 层圆圈层层倍增
- **转生系统**:晋升指数与转生倍率,点击晋升重开一局更强开局
- **多层级进阶**:无限 → 永恒 → 统一 → 时间流量,逐层解锁新维度
- **全自动化**:17 项自动化开关(自动晋升/自动无限/自动购买/自动抽卡…),挂机躺平
- **完整系统**:成就墙、商店、统计面板、里程碑、帮助与制作名单
- **标志性界面**:顶部彩色乘数链、左侧圆圈产量条、中央旋转轨道动画、转生窗口、底部"距离无限"进度条

## 开发环境

- 引擎:Godot 4.2.2 stable (.NET / mono)
- 语言:C#
- 构建:`dotnet build -c Debug`
- 运行:Godot 打开项目目录直接运行,或 `godot --path .`

## 目录结构

```
Scripts/
  Main.cs              # UI 主界面(乘数链/轨道/菜单/各页面)
  Autoload/GameManager.cs   # 存档、产出结算、自动化单例
  Core/BigDouble.cs    # 大数结构(支持 1e308+ 增量)
  Data/GameData.cs     # 存档数据模型
Assets/
  Fonts/               # 游戏字体
  UI/                  # 运行时美术(不入库,本地放置)
Scenes/Main.tscn       # 主场景
```

## 状态

可玩版本:从零开局的完整成长循环(买圈 → 转生 → 无限),12 个页面可切换浏览。
